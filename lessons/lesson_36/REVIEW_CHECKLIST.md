# Lesson 36 Review Checklist

Reviewed topics:

- `BLoC`: state changes should be event-driven and isolated from widgets.
- `Dependency Injection`: dependencies should be constructed outside the UI and passed inward.
- `Dio`: networking belongs in the data layer behind repository abstractions.
- `Drift`: local persistence belongs in datasource classes, not directly in widgets.
- `Animations`: presentation details stay in the view layer and should not leak into business logic.
