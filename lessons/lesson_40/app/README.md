# Lesson 40 App

This app completes the widget-testing homework for lesson 40.

## Implemented homework

- empty state, loading state, loaded list, and error state
- add-task flow with text input and button tap
- stable widget keys for important interactive elements
- task details navigation on item tap
- widget tests that use a fake repository instead of a real backend

## Important keys

- `taskInput`
- `addTaskButton`
- `loadTasksButton`
- `emptyState`
- `loadingIndicator`
- `errorMessage`
- `taskItem-<id>`
- `taskDetails`

## Run tests

```bash
flutter test
```
