# Lesson 31: Popular Flutter Packages

This application demonstrates the integration and usage of essential Flutter packages for production-ready applications.

## Features Implemented

✅ **freezed + json_serializable**
- Product model with immutable data class
- Auto-generated `fromJson` and `toJson` methods
- Type-safe model with `@freezed` annotation
- Generated code in `product.freezed.dart` and `product.g.dart`

✅ **cached_network_image**
- Efficient image caching from network URLs
- Placeholder widgets during loading
- Error widgets for failed image loads
- Smooth fade-in animations
- Memory and disk caching

✅ **intl**
- Date formatting with locale support (English/Russian)
- Currency formatting (RUB/USD)
- Number formatting based on locale
- Custom localization delegate
- Locale-specific string translations

✅ **go_router**
- Declarative routing with named routes
- Path parameters (e.g., `/products/:id`)
- Query parameters (e.g., `/products?category=electronics`)
- Type-safe navigation
- Error handling with custom 404 page

✅ **flutter_secure_storage**
- Secure token storage using platform-specific solutions
- iOS Keychain integration
- Android KeyStore integration
- Encrypted storage for sensitive data
- Demo authentication token management

## Packages Demonstrated

### 1. freezed (v2.5.8) + json_serializable (v6.9.5)
```dart
@freezed
class Product with _$Product {
  const factory Product({
    required int id,
    required String name,
    required double price,
    // ...
  }) = _Product;

  factory Product.fromJson(Map<String, dynamic> json) =>
      _$ProductFromJson(json);
}
```

### 2. cached_network_image (v3.4.1)
```dart
CachedNetworkImage(
  imageUrl: product.imageUrl,
  placeholder: (context, url) => CircularProgressIndicator(),
  errorWidget: (context, url, error) => Icon(Icons.broken_image),
)
```

### 3. intl (v0.20.2)
```dart
// Date formatting
DateFormat('dd MMMM yyyy', 'ru').format(date);

// Currency formatting
NumberFormat.currency(locale: 'ru_RU', symbol: '₽').format(price);
```

### 4. go_router (v14.8.1)
```dart
// Navigation with path parameters
context.push('/products/${product.id}');

// Navigation with query parameters
context.push('/products?category=electronics');
```

### 5. flutter_secure_storage (v9.2.4)
```dart
final storage = FlutterSecureStorage();
await storage.write(key: 'token', value: 'abc123');
final token = await storage.read(key: 'token');
```

## Key Concepts Demonstrated

### Code Generation Workflow
1. Define model with `@freezed` annotation
2. Add `part` directives for generated files
3. Run `build_runner` to generate code
4. Use generated `fromJson`/`toJson` methods

### Image Caching Strategy
- Network images automatically cached
- Placeholder shown during load
- Error handling for broken images
- Smooth transitions with fade animations

### Internationalization (i18n)
- Multiple locale support (en, ru)
- Date formatting per locale
- Currency formatting per locale
- Custom localization delegate

### Declarative Routing
- Routes defined in central configuration
- Type-safe parameter extraction
- Nested routes support
- Error handling

### Secure Data Storage
- Platform-specific encryption
- Keychain (iOS) / KeyStore (Android)
- Never store sensitive data in plain text
- Clear data on logout

- Date formatting requires `initializeDateFormatting` for Russian locale
- All route navigation is type-safe through go_router
- Product data is in-memory sample data (no real backend)
