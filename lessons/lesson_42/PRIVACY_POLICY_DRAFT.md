# Privacy Policy Draft

## Overview

This project is a course demo application prepared for release practice. The
current version does not intentionally collect personal user data, access the
camera, access the photo library, or send notifications.

## Data usage

- No account system is enabled in this lesson app.
- No analytics SDK is configured in this project.
- No advertising SDK is configured in this project.
- No personal profile data is collected by the app itself.

## Permissions

The app currently ships without dangerous Android runtime permissions. If a
future version adds camera, photo picker, notifications, or analytics, this
policy must be updated before release.
